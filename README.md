# ProyectosOsmar

Este repositorio contiene una calculadora web llamada **Calculadora Costo Rural**. La aplicación está pensada como un agente sencillo que ayuda a productores rurales a estimar de forma rápida el costo total de un proyecto agrícola o ganadero.

## ¿Cómo te puede ayudar el agente?

El objetivo principal del agente es que entiendas rápidamente cuánto dinero necesitas invertir para sacar adelante un proyecto rural. Estas son las maneras más comunes en las que te apoya:

- **Suma inmediata de tus costos**: ingresa los gastos de insumos, mano de obra, maquinaria y otros conceptos y el agente calcula el total de forma automática.
- **Prevención de olvidos**: al tener categorías separadas, te sirve como recordatorio para no pasar por alto rubros clave del presupuesto.
- **Formato amigable**: muestra el resultado en guaraníes con separadores de miles para que puedas leerlo y compartirlo fácilmente.
- **Trabajo 100 % local**: todo el cálculo ocurre en el navegador, sin necesidad de conexión a internet una vez abierto el archivo, ni instalaciones adicionales.
- **Iteraciones rápidas**: puedes modificar cualquier valor y recalcular las veces que quieras para evaluar distintos escenarios.

### Ejemplos de uso

- Preparar un presupuesto base antes de solicitar crédito o financiamiento.
- Comparar el impacto de usar un proveedor diferente para insumos.
- Estimar el costo final de una campaña específica (por ejemplo, una siembra puntual) cambiando solo los valores que varían.

## Cómo usarlo

1. Abre el archivo `index_Version2.html` en tu navegador preferido.
2. Introduce los montos de cada categoría de gasto en guaraníes.
3. Pulsa **Calcular costo total** para que el agente muestre el resultado estimado.

## Ejemplo

Si ingresas:

- Insumos: `1.000.000`
- Mano de obra: `850.000`
- Maquinaria: `600.000`
- Otros: `150.000`

El agente devolverá un costo total estimado de **Gs 2.600.000**.
